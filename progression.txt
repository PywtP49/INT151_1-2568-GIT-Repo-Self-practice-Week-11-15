PROGRESSION — WEEK 11–13 (SUMMARY)

Week 11, 12 และ 13 ทั้งหมดเป็นช่วงที่เน้นให้เข้าใจ “โครงสร้างการทำงานของเว็บแบบจริงจัง” ตั้งแต่ ดึงข้อมูล → จัดการ → แสดงผล → คำนวณต่าง ๆ โดยภาพรวมจะเห็นลำดับความยากเพิ่มขึ้นทีละนิด และทุกสัปดาห์เชื่อมโยงกัน

====================================================
WEEK 11 — API + MODULE + CRUD (เริ่มทำเว็บแบบจริง)

สัปดาห์นี้คือพื้นฐานใหญ่ของการทำเว็บที่ต้องดึงข้อมูลจากภายนอก มีระบบ และแยกโค้ดอย่างมีระเบียบ

โฟกัสคือ
“อ่านข้อมูลจาก API แสดงผลบนหน้าเว็บ เพิ่มข้อมูลใหม่ ลบข้อมูลเก่า และทำทุกอย่างแบบ async”

เริ่มจากทำ JSON Server เพื่อจำลอง API เหมือนของจริง → สร้าง fetchUtils ไว้ใช้ซ้ำทุกที่ → สร้าง quoteManagement.js ไว้จัดการ data โดยไม่ยุ่งกับ HTML → แล้วสุดท้าย app.js มาควบคุม UI

สเต็ปหลัก ๆ:

โหลดคำคมตอนเปิดหน้า

เพิ่มคำคมใหม่ด้วยการโพสต์ข้อมูล

ลบคำคมด้วยการยิง DELETE

ทุกครั้งที่เพิ่ม/ลบให้โหลดใหม่

หากเกิด error ต้องจับด้วย try/catch

ผลที่ควรได้คือเว็บที่ดึงข้อมูลจาก API จริง ๆ (ถึงจะเป็น JSON Server ก็เถอะ) และผู้ใช้สามารถเพิ่ม/ลบข้อมูลได้แบบไหลลื่น

นี่คือสัปดาห์ที่เริ่ม “รู้สึกเหมือนเขียนเว็บจริง”

====================================================
WEEK 12 — FETCH EXERCISE + REST API (เน้นความแม่น)

หลังจากทำ CRUD ไปแล้ว อาทิตย์นี้คือการตอกย้ำวิธีใช้ Fetch API แบบแม่น ๆ

โจทย์เน้นที่:

เข้าใจโครงสร้างของ Response

รู้ว่าวิธีเช็ค error ที่ถูกต้องคือ res.ok

ใช้ async/await ให้เป็น flow

และสุดท้ายคือการแสดงผล DOM แบบ basic แต่ชัดเจน

ไม่มี CRUD เหมือนสัปดาห์ 11 แต่เน้นการ “อ่านข้อมูลและโชว์ให้สวยงาม” เช่น รายการสินค้า รายการข้อมูลทั่วไปจาก API ภายนอก

โปรเจกต์สัปดาห์นี้เหมือน Mini Testing Ground ให้คุณมั่นใจว่า

“โอเค เรา fetch API เป็น แสดงผลเป็น และจัดการ error เป็นแล้ว”

====================================================
WEEK 13 — DATE/TIME (เข้าใจการจัดการเวลาในเว็บ)

อาทิตย์สุดท้ายในชุดนี้คือเรื่องวันที่และเวลา การจัดการเวลาคือหนึ่งในของที่เจอบ่อยสุดเวลาเขียนเว็บ เช่น คำนวณอายุ นับถอยหลัง แปลงรูปแบบวันเวลา หรือแสดงเวลาปัจจุบัน

เนื้อหาหลักคือ:

การอ่านเวลาปัจจุบันด้วย new Date()

การดึงส่วนประกอบ เช่น ปี เดือน วัน ชั่วโมง นาที

ทำความเข้าใจว่าบางฟังก์ชันเริ่มนับจาก 0 เช่น getMonth()

การคำนวณอายุจากสองวันที่ต่างกัน

การคำนวณส่วนต่างของเวลา (เช่น ยังเหลืออีกกี่วันก่อนถึงปีใหม่)

หลังเข้าใจเรื่องนี้ เราสามารถทำฟีเจอร์ที่ “ผู้ใช้มองเห็นผลทันที” เช่น ตัวนับเวลา countdown, real-time clock, หรือระบบที่ต้องระบุช่วงเวลาได้

สัปดาห์นี้คือการปิดท้ายด้วยเนื้อหาที่ใช้งานจริงมาก ๆ ในโปรเจกต์ทั่วไป
